# Manual: Start a Hobby Blog on GitHub Pages for Free

Welcome. This manual walks you — step by step, in plain English — from
"thinking about starting a blog" to publishing your first post on GitHub
Pages without spending a dime and without creating any accounts beyond
a GitHub login you probably already have.

Read it like a friend talking you through it. Every chapter stands on
its own, so you can jump to the topic you need.

## Who this is for

- A hobbyist (gardening, chess, gaming, woodworking, bookbinding, cat
  photography — anything) who wants to write about it.
- A beginner who has never deployed a website before.
- Someone who wants the site to be *yours*: plain files, no platform
  lock-in, no monthly bill.

## What you get at the end

- A public blog at `https://yourname.github.io/your-repo/`
- Built from Markdown files you can edit in any text editor
- A local folder that is also your entire backup
- Zero cost, zero accounts on third-party services, zero tracking

## How to use the repo

- `docs/` — this manual, in Markdown.
- `content/posts/` — example post sources (Markdown), the same format
  you will use for your own posts.
- `site/` — a small, complete static-blog example. It is both part of
  the manual and a working blog you can open locally right now.
- `tools/` — tiny, dependency-free Python scripts that build and check
  the site. They are intentionally readable so you can adapt them.

## Local first

Everything here runs on your machine with only Python 3 and `git`
installed. No accounts, no API keys, no personal data. You can fork it,
rename everything, and repurpose it for your own niche blog in an
afternoon.
